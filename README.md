# 💻 Windows 10 — Веб-симуляция (Монолит)
*hide: как можно увидеть по 6 строке, этот сайт сделан именно с помощью v0 by Vercel (я туда опубликовал [сайт](https://v0-windows10-app.vercel.app)

Интерактивная браузерная симуляция операционной системы Windows 10, написанная полностью на ванильном стеке технологий (**HTML5, CSS3 и чистый JavaScript**). Весь проект упакован в один-единственный независимый файл `index.html`.

## 🚀 Особенности проекта

* **Архитектура «Монолит»:** Никаких внешних тяжелых библиотек, фреймворков (React/Vue/Svelte) или npm-пакетов. Всё работает «из коробки» в любом браузере.
* **Полный цикл загрузки:** Симуляция включает в себя экран загрузки (Boot Screen) с фирменной анимацией, экран блокировки (Lock Screen) с часами и страницу авторизации.
* **Оконный менеджер:** Полноценная поддержка многооконности с динамическим расчетом `z-index` (фокусировка на активном окне), возможностью перетаскивания (Drag-and-Drop), сворачивания и разворачивания на весь экран.
* **Кастомные SVG-иконки:** Все системные иконки перерисованы в векторе (в стиле Fluent Design) и вшиты прямо в код страницы для мгновенной загрузки.
* **Аутентичный визуал:** Использование оригинальных Hero-обоев Windows 10, эффектов размытия панелей (`backdrop-filter`) и системных шрифтов.

## 📱 Встроенные приложения

1.  📝 **Блокнот (Notepad):** Текстовый редактор с поддержкой ввода текста.
2.  🧮 **Калькулятор (Calculator):** Полностью рабочий инструмент с обработкой базовых математических операций и исключений (например, деление на ноль).
3.  🌐 **Microsoft Edge:** Симуляция веб-браузера со стартовой страницей быстрых закладок и возможностью загрузки сторонних сайтов через `iframe`.
4.  📁 **Проводник (File Explorer):** Файловый менеджер с навигацией по разделам («Быстрый доступ», «Документы», «Изображения») и возможностью открывать текстовые файлы двойным кликом.
5.  ⚙️ **Параметры (Settings):** Панель управления, позволяющая менять обои рабочего стола, выбирать цвет акцента системы и просматривать характеристики виртуального ПК.
6.  🗑️ **Корзина (Recycle Bin):** Классический компонент рабочего стола.

## 🛠️ Технологический стек

* **HTML5:** Семантическая разметка и структура интерфейса.
* **CSS3:** Flexbox и Grid для сетки приложений, Tailwind-подобные переменные для кастомизации тем, анимации вращения и размытие.
* **Vanilla JS:** Модульные рендереры для каждого приложения, обработчики мыши (`mousedown`, `mousemove`, `mouseup`) для перетаскивания и изменения размеров окон, обновление системного времени в реальном режиме.

## 📦 Как запустить

Поскольку это монолитный проект, запуск не требует сборки:

1.  Скачайте или скопируйте файл `index.html`.
2.  Дважды кликните по файлу, чтобы открыть его в любом современном браузере (Chrome, Edge, Firefox, Safari).
3.  На экране блокировки кликните мышкой, введите любой пароль (или оставьте поле пустым) и нажмите **Enter**.
